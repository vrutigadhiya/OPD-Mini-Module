START HERE
==========

1. Unzip this folder.
2. Install Java 17, Maven, Node.js LTS, Angular CLI, and MySQL.
3. Start MySQL and create database `opd_db` (or allow createDatabaseIfNotExist).
4. Edit backend/src/main/resources/application.properties:
   spring.datasource.username=root
   spring.datasource.password=YOUR_MYSQL_PASSWORD
5. Terminal 1:
   cd backend
   mvn spring-boot:run
6. Terminal 2:
   cd frontend
   npm install
   npm start
7. Open http://localhost:4200

Read README.md for the API list, flow explanation, and interview/demo talking points.
This is a learning/demo project, not a production medical record system.

Optional sample reports screen: open the Reports tab to see total patients, appointments today, booked appointments, and completed consultations. Basic login was optional and is not included in this demo.
